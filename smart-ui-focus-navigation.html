Work sample

Solving the focus problems that show up in real menus.

Smart UI Focus & Navigation is a current LevelArgento Unity project focused on dependable menu navigation rather than replacing the entire UI framework.

01

Automatic focus recovery

Recover when the currently selected uGUI control becomes inactive, disabled, or non-interactable.

02

Remembered selection

Restore the exact selection when users leave and return to a menu or focus scope.

03

Modal restoration

Open a modal and return focus to the exact control that launched it when the modal closes.

04

Smarter directional navigation

Handle irregular layouts and ragged grids while still allowing per-direction Auto, None, and Explicit overrides.

Current development status

Built and validated in Unity.

The current development baseline has been validated in Unity 6000.3.19f1 with uGUI and the New Input System. The project includes automated EditMode coverage for focus management, input mode detection, dynamic navigation, layout constraints, navigation overrides, and directional navigation utilities.
