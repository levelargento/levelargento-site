    Getting started¶

    This setup adds default focus, selection memory, and invalid-selection recovery to an existing uGUI menu.

    Configure the scene¶

    1. Ensure the scene contains one active EventSystem with InputSystemUIInputModule.
    2. Add SmartFocusManager to a scene object and assign the EventSystem.
    3. Add SmartFocusScope to the root of a menu or panel.
    4. Assign a valid child Selectable to Default Selection.
    5. Leave Remember Last Selection enabled if returning to the menu should restore its last valid selection.
    6. Assign the scope to the manager's Initial Scope, or call SetScope when the menu opens.
    7. For mouse-aware focus recovery, add SmartInputModeDetector, assign its UI action references, and assign the detector to the manager.
    8. Enter Play Mode and test with keyboard and gamepad navigation.

    The scope and its default control must be active when focus is requested.

    Switching menus from code¶

    using LevelArgento.SmartUINavigation;
using UnityEngine;

public sealed class MenuController : MonoBehaviour
{
    [SerializeField] private SmartFocusManager focusManager;
    [SerializeField] private GameObject optionsPanel;
    [SerializeField] private SmartFocusScope optionsScope;

    public void OpenOptions()
    {
        optionsPanel.SetActive(true);
        focusManager.SetScope(optionsScope);
    }

    public void CloseOptions()
    {
        focusManager.SetScope(null);
        optionsPanel.SetActive(false);
    }
}

    SetScope(null) stops monitoring a scope but does not itself clear or change the EventSystem selection. If another menu opens, activate it and call SetScope with its scope.

    Requesting a specific selection¶

    using LevelArgento.SmartUINavigation;
using UnityEngine;
using UnityEngine.UI;

public sealed class FocusShortcut : MonoBehaviour
{
    [SerializeField] private SmartFocusManager focusManager;
    [SerializeField] private Button target;

    public void FocusTarget()
    {
        focusManager.RequestFocus(target);
    }
}

    RequestFocus returns false if the target is outside the current scope, inactive, disabled, or non-interactable.

    Optional smart navigation¶

    For menus that need generated directional links, add SmartNavigationGroup to a common ancestor of the participating controls. It rebuilds after layout and hierarchy changes by default. See smart navigation before applying it to an existing navigation setup, because rebuilding writes Navigation.Mode.Explicit links.
