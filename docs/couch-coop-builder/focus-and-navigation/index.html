    Built-in Focus and Navigation¶

    Couch Co-op Builder contains its own focus and navigation implementation for the Setup Wizard, supplied lobbies, Rocket Rumble menus and Split Screen Playgrounds. It works without another LevelArgento product. The separate Smart UI Focus & Navigation product is not included and is not required.

    Player-owned focus¶

    PlayerFocusManager controls one assigned EventSystem. In a multiplayer panel it uses that player's MultiplayerEventSystem and input module; it never substitutes another player's global EventSystem. The Wizard creates and connects these components automatically in the Existing Canvas workflow.

    PlayerFocusScope defines the selectable region. On scope assignment the manager selects a valid remembered control, the default selection, or a valid descendant, in that order. Disabled, inactive, non-interactable and out-of-scope controls cannot receive focus. Clear remembered selection when opening a panel that should always start on its default control.

    Modals and input modes¶

    The sample menus push a modal scope for binding capture and reset confirmation. Closing a modal returns to the prior scope/control when still valid, or recovers a valid selection. Destroyed objects and unavailable EventSystems are tolerated during teardown.

    PlayerUiInputModeDetector observes only the actions assigned to its owned InputSystemUIInputModule. Keyboard/controller interaction permits automatic focus recovery. Pointer mode avoids immediately reclaiming a mouse-cleared selection. It does not create input users, pair devices, enable other players' actions or change Join/Leave behavior.

    Navigation groups and overrides¶

    UiNavigationGroup generates explicit directional links for the small authored Playground panels. It excludes inactive/non-interactable controls and controls belonging to a nested group. UiNavigationOverride can direct an edge to a particular valid control or intentionally leave it unlinked. Existing explicit links elsewhere, including the per-player lobby and Rocket Rumble menu routing, remain authored by those workflows.

    Samples¶

    Study lobby templates and Existing Canvas, Rocket Rumble menus, and Split Screen Playgrounds. The built-in module is product-specific; it does not include the standalone product's inspectors, layout constraints, showcases, documentation or branding.

    Installation and updates¶

    The module lives under Assets/LevelArgento/CouchCoopBuilder/Runtime/UI/FocusNavigation/ and uses the Couch-owned LevelArgento.CouchCoopBuilder.UI assembly. Keep it with Couch. No standalone-product installation or compatibility fingerprint is needed. Back up customer-authored scenes and scripts before updating Couch.
